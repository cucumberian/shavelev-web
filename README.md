# Таблицы Шевелева — веб-клон

Функциональный HTML/JS-клон программы «Таблицы Шевелева» ver 3.0 (БрГТУ, 2008) —
гидравлический расчёт водопроводных труб по справочнику Шевелевых (1984).
Восстановлен реверс-инжинирингом оригинального VB6 EXE: формулы, константы и
справочники диаметров извлечены из кода программы; книга — только кросс-проверка.

## Запуск

Двойной клик по `index.html` — работает прямо с `file://`, без сервера и сборки.
Или: `python3 -m http.server 8899` в этой папке → `http://<host>:8899/`.

## Возможности

- 11 материалов: сталь ВГП ГОСТ 3262, электросварные ГОСТ 10704 (dв = dн − 2s по
  толщине стенки), чугун 9583, а/ц 539 (ВТ6–ВТ15, типы 1–3), ПВХ 18599, ж/б 12586,
  стеклопластики СП 40-104-2001, стекло 8894, **медь СП 40-108-2004** (dн 6…267 мм + толщина S,
  dв = dн − 2S, свои формулы и ξ местных сопротивлений), PEX СП 40-108-2004, PEX-AL-PEX СП 41-109-2005
- новые / неновые трубы; режимы водопровода с лимитами скорости
- ν и ρ теплоносителя с пресетами по температуре
- вывод: v, 1000i (мм/м), R (Па/м), H = i·L·(1+k), потери Па; предупреждения и
  экономические рекомендации по диаметру — как в оригинале. На медной странице местные
  сопротивления задаются списком ξ (не k): H = i·L + V²Σξ/2g, ΔP = R·L + Z, Z = 0,5ρV²Σξ
- «Справка» со всеми расчётными формулами

## Структура

```
index.html      — разметка формы
styles.css      — стили (Win-classic)
js/formulas.js  — формулы λ/A=λ/(2g), i=A·v²/d^e  (VA-адреса констант: см. AGENTS.md)
js/data/            — справочники, по модулю на тип труб (steel.js … metal-pex.js)
js/data/registry.js — реестр: registerMaterial/registerRec → MATERIALS/ECON_ROWS
js/data/docs.js     — подписи ГОСТ/СП
js/data/modes.js    — лимиты скорости, режимы участка, k, порог VREC
js/data/index.js    — сборка всех модулей для node-тестов
js/calc.js      — расчётный движок: v, i, R, H, k, предупреждения, рекомендация, fmt (без DOM)
js/ui.js        — заполнение списков, чтение контролов, вывод, справка
test/           — node-тесты (не входят в коммит программы)
```

## WebMCP

Страница регистрирует [WebMCP](https://github.com/webmachinelearning/webmcp)-инструменты
через `document.modelContext.registerTool` (см. `js/webmcp.js`):

| инструмент | назначение |
|---|---|
| `shev-list-materials` | материалы, диаметры, режимы и лимиты скорости |
| `shev-configure` | выставить материал/состояние/диаметр/стенку/режим/ν/ρ; для меди — cu_system (cold/circ/supply/heat) и t_c (50…90) |
| `shev-calculate` | расчёт участка → v, i, R, H, dP, предупреждения (структурированно); для меди — xi_total (Σξ) |
| `shev-get-formulas` | формулы программы для объяснения результата |

В браузерах без нативного `modelContext` включается polyfill: авторские агенты
и тесты получают тот же контракт через `window.webmcp.getTools()` /
`window.webmcp.executeTool(name, args)`. Инструменты работают через UI
(выбор в списках, кнопка «Расчёт») — экран всегда синхронен с действиями агента.

## Модель расчёта

`i [м/м] = A·v²/d^e`, где `A ≡ λ/(2g)` — ν-подставленные формы программы;
`R = ρ·g·i`, `H = i·L·(1+k)`, `g = 9,81`, `2g = 19,62` (свёрнуто в константы λ).
Ветвление неновых: v ≥ 1,2 → A = 0,00107; v < 1,2 → A = 0,000912·(1+0,867/v)^0,3.

Ж/б (ГОСТ 12586.0-83): `i = 0,000802·φ·v²/dp^1,190·(1+3,51/v)^0,190` (φ = 1), Ø dу 500…1600 мм,
dв = dу; формула одна для новых и неновых труб, ν = 1,3·10⁻⁶ (t = 10 °C) вшита в константы,
местные сопротивления не учитываются: `H = i·L`.
Эталон: d = 600 мм, Q = 70 л/с, L = 100 м → v = 0,248 м/с, 1000i = 0,151 мм/м, h = 0,015 м
(скрин оригинала 06.10.2026).

Стеклопластик (СП 40-104-2001): страница считает двумя формулами, как в её справке —
`λ = 0,0146·(v·dp)^−0,226`, `i = λ·v²/(2g·dp)` (в модели клона A = λ/19,62, e = 1); Ø внутренние
50…400 мм (13 значений списка программы), dв = d; формула одна для новых и неновых труб,
ν = 1,3·10⁻⁶ (t = 10 °C) вшита в константы, местные сопротивления не учитываются: `H = i·L`.
Эталон: d = 60 мм, Q = 4 л/с, L = 100 м → v = 1,415 м/с, 1000i = 43,344 мм/м, h = 4,334 м
(скрин оригинала 07.10.2026).

Стекло (ГОСТ 8894-86): `i = 0,000745·v^1,774/dp^1,226` (FUN_0050daf0); в комбо — **наружные** dн
45, 67, 93, 122, 169, 221 мм (6 значений списка программы), а внутренний dв подставляет сама
программа по таблице: 45→37, 67→57, 93→81, 122→108, 169→150, 221→198 мм (FUN_0050d4c0); флажок
«другой» — ручной расчётный dp. Формула одна для новых и неновых труб, ν = 1,3·10⁻⁶ (t = 10 °C)
вшита в константы, местные сопротивления не учитываются: `H = i·L`.
Эталоны: dн = 93 мм (dв = 81 мм), Q = 7 л/с, L = 100 м → v = 1,358 м/с, 1000i = 27,949 мм/м,
h = 2,795 м (скрин оригинала 07.10.2026); dн = 45 мм (dв = 37 мм), Q = 7 л/с, L = 100 м →
v = 6,510 м/с, 1000i = 1177,269 мм/м, h = 117,727 м (живая программа, 07.10.2026).

Медь (страница «для медных труб СП40-108-2004», FUN_00515500) — единственная страница, где местные
сопротивления заданы списком ξ (12 позиций Приложения А + «другие ξ»), а не коэффициентом k, и где ν и ρ
подставляются по температуре. Формулы скачанного СП 40-108-2004 (docs/sp40-108-2004/, константы сверены
с EXE): i = 0,0161·ν^0,25·V^1,75/d^1,25 — холодное водоснабжение и циркуляционные линии ГВС;
i = 0,051·((6,52·lg d + lg(Vd/ν))/(115·lg²d) + (0,66·lg d + 0,1·lg(Vd/ν))/(lg(Vd/ν)·lg d))·V²/d —
подающие линии ГВС; R = λ·V²/(2d)·10³ Па/м, где √λ = 0,5·[b/2 + 1,312(2−b)·lg(3,7d/Kз)/(lg Re − 1)]/lg(3,7d/Kз),
Re_кз = 500d/Kз, b = 1 + lg Re/lg Re_кз, Kз = 10⁻⁵ — системы отопления (g = 9,80665, не 9,81).
Комбо — наружные dн 6…267 мм (20 значений AddItem) + связанная толщина S, dв = dн − 2S (FUN_005148a0).
Лимиты скорости: 4 (ХВС) / 3 (циркуляция) / 3 (подающие) / 2 (отопление) м/с. Блоки «Температура» и «Теплоноситель»
— отдельные, как в оригинальном окне, и гасятся целиком по системе: «холодного водоснабжения» — оба неактивны
(вода ν = 1,3·10⁻⁶, ρ = 1000), «циркуляционного» и «подающего» ГВС — активен только «Температура», «системы
отопления» — активны оба (там же «другой» теплоноситель с ручными ν и ρ).
Точки клона (вычислены по формулам СП; живой эталон меди ещё не снят — Wine на этом хосте не запускается):
dн = 22 мм, S = 1,0 мм (dв = 20 мм), Q = 1 л/с, L = 100 м → холодное водоснабжение (ν = 1,3·10⁻⁶, ρ = 1000):
v = 3,183 м/с, 1000i = 548,292 мм/м, R = 5376,9 Па/м, H = 54,829 м; циркуляционный ГВС t = 50 °C
(ν = 0,55·10⁻⁶, ρ = 990): 1000i = 442,198, R = 4293,1, H = 44,22; подающие ГВС — 1000i = 1378,873;
отопление t = 50 °C — R = 5277,1 Па/м. С ξ = 4,8 (циркуляция): H = 46,699 м, ΔP = 453386 Па.
