# Папка `gost` — нормативные документы страниц

В оригинальной программе ссылки на СП/ГОСТ открывают файлы из папки `gost` рядом с программой
(например, `gost\sp41_102_98.doc`). В клоне ссылки в справке указывают на те же имена файлов —
чтобы они работали, положите сюда соответствующие документы:

- `sp41_102_98.doc` — СП 41-102-98 (страница PEX-AL-PEX)
- `sp40_102_2000.doc` — СП 40-102-2000 (страницы PEX и PEX-AL-PEX)

Сама программа .doc-файлы не поставляет (в поставке клона их нет).
Если документа нет, ссылка просто откроет пустую страницу — расчёт от этого не зависит.
