# AGENTS.md — правила работы с этим репозиторием для AI-агентов

## Репозиторий
- Основной (единственный актуальный): https://github.com/cucumberian/shavelev-web, ветка `main`.
- Старый `mininish/shevelev-web` заархивирован — в него ничего не пушить.

## Пуш — только после согласования
- **Запрещено** пушить в репозиторий без явного согласия пользователя в текущей сессии.
- Разрешено: править файлы локально, коммитить локально, гонять тесты.
- Перед демонстрацией результата пользователю — показать скриншоты/вывод, дождаться «коммить/пушь».

## Структура и модульность (не нарушать)
- `index.html` — только разметка; `styles.css` — все стили (никаких inline-стилей контролов);
- `js/formulas.js` — формулы (при изменении — дополнять комментарий VA-адресом константы из реверса);
- `js/data.js` — справочники (диаметры/стенки/ECON/VEL_LIMIT), источник — EXE-реверс, не выдумывать значения;
- `js/ui.js` — UI/валидация/расчёт; `js/webmcp.js` — WebMCP-инструменты (регистрация после ui.js).
- Файлы подключаются обычными `<script>` в порядке: formulas → data → ui → webmcp. Не переводить в ES-модули: клон обязан открываться двойным кликом с `file://`.

## Тесты — обязательны перед любым коммитом
```
cd test && node test.js && node ui_test.js && node edge_test.js && node webmcp_test.js
```
Все должны быть PASS (33 + 178 + 206 + 40). Быстрые проверки вёрстки в реальном браузере:
headless Chromium (`--headless=new --screenshot`, iframe-пробы переполнения через `--dump-dom` + `document.title`).

- Мобильная вёрстка: брейкпоинты 820px (колонки) и 480px (телефон); контролы ≥16px шрифта (анти-зум iOS).
